# 🔎 Real Search

> A lightweight search engine built with Node.js, TypeScript and MySQL.

## 🔍 Search Modes

### 🌐 Standard
Natural language search with automatic query expansion.

![Standard Mode](screenshots/standard.png)

### 🎯 Exact
Boolean search for exact phrases.

![Exact Mode](screenshots/exact.png)

### ⚙️ Manual
Full control over search operators (`+`, `-`, `"`, `*`).

![Manual Mode](screenshots/manual.png)

## 🛠️ Tech Stack

- TypeScript
- Node.js
- Express.js
- MySQL
